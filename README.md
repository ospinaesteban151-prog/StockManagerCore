📦 StockManager CoreStockManager Core es una solución robusta de software de escritorio (Aplicación de Consola Interactiva - CLI) desarrollada en C# y SQL. Está diseñada para la gestión integral de inventarios de pequeñas y medianas empresas, permitiendo controlar categorías, administrar existencias, aplicar estrictas reglas de negocio y generar reportes analíticos exportables.🎯 Objetivo del SistemaProveer un entorno rápido, confiable y seguro para el control de inventario mediante Programación Orientada a Objetos (POO) y persistencia en bases de datos relacionales, garantizando la integridad de los datos sin depender de APIs web.✨ Características PrincipalesGestión de Categorías: CRUD completo con validación contra duplicados y restricciones de eliminación de seguridad.Control de Productos: Administración detallada de inventario, asegurando stock y precios válidos, y vinculación obligatoria a categorías existentes.Control de Stock Seguro: Operaciones atómicas para entradas y salidas de mercancía garantizando que el stock nunca sea negativo.Reportes Analíticos y Exportación: Generación de alertas de stock bajo y valorización total del inventario (mediante consultas SQL avanzadas tipo JOIN y GROUP BY), con exportación automática a archivos planos (.txt / .csv).Interfaz Robusta (CLI): Navegación ininterrumpida mediante un menú interactivo con manejo global de excepciones para evitar cierres inesperados por errores de usuario.🛠️ Tecnologías y ArquitecturaLenguaje: C# (.NET)Base de Datos: SQL Server / PostgreSQLAcceso a Datos: ADO.NET / Entity Framework CoreArquitectura: Separación de responsabilidades en capas lógicas (Modelos, Datos, Negocio).👥 Equipo y Módulos de DesarrolloEste proyecto fue estructurado modularmente y desarrollado por un equipo de 5 personas:IntegranteRol / MóduloFuncionalidad PrincipalIntegrante 1Base de Datos & ArquitecturaDiseño del modelo relacional, llaves primarias/foráneas y conexión centralizada.Integrante 2Gestión de CategoríasCRUD de categorías, validación de duplicados y restricción de borrado.Integrante 3Gestión de ProductosCRUD de productos, validación de existencias y actualización de stock.Integrante 4Reportes SQL AvanzadosConsultas relacionales (JOIN/agregaciones) y exportación de archivos .txt/.csv.Integrante 5Interfaz (CLI) & ErroresMenú interactivo, integración general y captura de excepciones (try-catch).📋 Requerimientos del SistemaRequerimientos Funcionales (RF)RF-01 (Categorías): Registro, consulta, edición y baja. Bloqueo de eliminación si existen productos asociados.RF-02 (Productos): Registro, actualización y consulta vinculados obligatoriamente a una categoría válida.RF-03 (Control de Stock): Operaciones de suma/resta de existencias sin permitir valores negativos ni precios en 0.RF-04 (Reportes Analíticos): Alertas de bajo stock (≤ 5 unidades) y cálculo de la valorización total.RF-05 (Exportación): Generación física de archivos en el directorio local Reportes/.Requerimientos No Funcionales (RNF)RNF-01 (Tolerancia a Fallos): El sistema captura entradas inválidas (ej. letras por números) sin cerrarse (Crash-proof).RNF-02 (Integridad de Datos): Restricciones relacionales (FOREIGN KEY, CHECK) aplicadas directamente en el motor SQL.RNF-03 (Mantenibilidad): Código con alta cohesión y bajo acoplamiento gracias a la división en capas lógicas.🚀 Cómo ejecutar el proyectoClona este repositorio:git clone https://github.com/tu-usuario/StockManager-Core.git
Configura tu cadena de conexión en el archivo de configuración (ej. appsettings.json).Ejecuta el script SQL incluido en la carpeta Database/ para inicializar las tablas y restricciones.Compila y ejecuta la aplicación desde tu IDE (Visual Studio / Rider) o usando la CLI de .NET:dotnet run
